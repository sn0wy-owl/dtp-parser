# Парсер ДТП с сайта ГИБДД

Проект для массовой загрузки и обработки данных о ДТП с [сайта статистики ГИБДД](http://stat.gibdd.ru) за указанный период.  
Данные собираются по регионам и месяцам, парсятся и сохраняются в формате Parquet с партиционированием по годам и месяцам.

---

## Функционал

- ✅ Загрузка справочника регионов
- ✅ Последовательный опрос API по году, месяцу и региону
- ✅ Обработка вложенной структуры JSON
- ✅ Парсинг информации:
  - О ДТП (дата, время, координаты, тип)
  - О погоде и состоянии дороги
  - Об участниках, водителях, ТС
- ✅ Сохранение в parquet с партиционированием: `year=2023/month=01/...`
- ✅ Проверка существования данных: можно пропустить или перезаписать
- ✅ Логирование в файл и консоль
- ✅ Возобновление после остановки
---

## Использование

1. Клонируйте репозиторий и установите зависимости:
```
   git clone https://github.com/sn0wy-owl/dtp-parser.git
   cd dtp-parser
   pip install -r requirements.txt
```

2. Запустите парсер
```
    python main.py
```

## Выходные данные

Результат сохраняется как партиционированный Parquet-датасет:

data/all_accidents.parquet/    
├── year=2016/  
│   ├── month=1/ → part-00001.parquet  
│   └── ...  
└── ...  

Как читать:
```
    import pandas as pd

    # Полный датасет
    df = pd.read_parquet('data/all_accidents.parquet')

    # Только за 2023 год
    df = pd.read_parquet('data/all_accidents.parquet', filters=[('year', '=', 2023)])

```

## Повторный запуск
При запуске:

Проверяется, есть ли данные за каждый (год, месяц)
Если есть — предлагается:
1. Перезаписать
2. Пропустить
3. Перезаписать (запомнить для всех)
4. Пропустить (запомнить для всех)

# **Структура датасета ДТП**

| № | Поле | Тип | Примеры значений | Описание | Как получено |
|---|------|-----|------------------|----------|--------------|
| 1 | **`id`** | `string` | `b3b2fab11f7fd19c`, `1d9703ce96272ac0` | Уникальный идентификатор ДТП | SHA256 хеш от даты, времени и координат (первые 16 символов) |
| 2 | **`datetime`** | `datetime` | `2016-01-31 14:40:00` | Полная дата и время ДТП | Объединение полей `date` и `time` |
| 3 | **`lat`** | `float` | `52.28114`, `53.3844` | Широта | Очищенные координаты, невалидные заменены на `NaN` |
| 4 | **`lng`** | `float` | `85.10139`, `81.2194` | Долгота | Очищенные координаты, невалидные заменены на `NaN` |
| 5 | **`dtp_type_group`** | `string` | `Столкновения`, `Наезды`, `Потеря управления` | Группа типа ДТП | Агрегация из `dtp_type` (12 основных групп) |
| 6 | **`dtp_type`** | `string` | `Столкновения транспортных средств`, `Наезды на пешеходов` | Детальный тип ДТП | Сгруппировано из 19 оригинальных типов |
| 7 | **`weather_base`** | `string` | `Ясно`, `Пасмурно`, `Снег` | Базовая погода | Определена по приоритету (туман > дождь > снег > пасмурно > ясно) |
| 8 | **`extreme_temp`** | `str` | `-30`, `+30` | Флаг экстремальной температуры | `True` если температура ниже -30°C или выше +30°C |
| 9 | **`road_code`** | `string` | `Р-256`, `А-322`, ` ` | Код дороги | Извлечен из `road_title` (только официальные коды) |
| 10 | **`car_mark`** | `string` | `ВАЗ`, `TOYOTA`, `NISSAN` | Марка автомобиля | Очищенная и стандартизированная марка |
| 11 | **`car_model`** | `string` | `ВАЗ 2115 и модификации`, `Camry` | Модель автомобиля | Оригинальное значение |
| 12 | **`color`** | `string` | `Иные цвета`, `Серый`, `Белый` | Цвет автомобиля | Оригинальное значение |
| 13 | **`car_year`** | `int` | `2001`, `2011`, `1998` | Год выпуска автомобиля | Оригинальное значение |
| 14 | **`driver_gender`** | `string` | `Мужской`, `Женский`, `Не определен` | Пол водителя | Оригинальное значение |
| 15 | **`driver_exp`** | `int` | `16`, `0`, `95` | Стаж вождения (лет) | Оригинальное значение |
| 16 | **`driver_alco`** | `string` | `11`, `25`, `08`, ` ` | Степень опьянения | Пустое значение = трезв |
| 17 | **`driver_violation_category`** | `string` | `Выезд на встречную полосу`, `Превышение скорости`, `Нет нарушений` | Категория нарушения | Классифицировано из списка нарушений |
| 18 | **`passenger_count`** | `int` | `1`, `2` | Количество пассажиров в машине, не считая водителя | Считается суммой пассажиров в машине |
| 19 | **`death_count`** | `int` | `1`, `2` | Количество погибших в ТС | Считается суммой по всем находившихся в машине с травмами, где указанно 'Скончался' |
| 20 | **`wounded_count`** | `int` | `1`, `2` | Количество ранненых в ТС | Считается суммой по всем находившихся в машине с травмами, где указанно 'Раненый' |
| 21 | **`year`** | `int` | `2016`, `2024` | Год ДТП | Извлечен из `datetime` |
| 22 | **`month`** | `int` | `1`, `10`, `12` | Месяц ДТП | Извлечен из `datetime` |
